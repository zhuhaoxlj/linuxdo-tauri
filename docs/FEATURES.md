# 功能特性详解

## 一、知识看板模块

### 1.1 快速启动设计

**设计理念**
- 应用启动后直接显示看板，无需额外点击
- 默认进入「首页」分类
- 数据从 localStorage 快速加载，启动时间 < 500ms

**技术实现**
- React 懒加载优化首屏加载
- Vite 构建优化和代码分割
- Tauri 原生窗口，启动速度快

### 1.2 分类系统

| 分类 | 图标 | 颜色 | 用途 |
|------|------|------|------|
| 首页 | 🏠 | 靛蓝 | 综合待办和快速入口 |
| 生活 | 🌟 | 绿色 | 个人生活相关任务 |
| 工作 | 💼 | 橙色 | 工作项目和任务 |
| 知识库 | 📚 | 紫色 | 学习笔记和资料整理 |
| 娱乐 | 🎮 | 粉色 | 休闲娱乐计划 |
| LinuxDo | 🐧 | 青色 | 论坛集成入口 |

**自定义分类**
可以在 `src/modules/board/context/BoardContext.jsx` 中修改 `DEFAULT_CATEGORIES`：

```javascript
const DEFAULT_CATEGORIES = [
  { id: 'custom', name: '自定义', icon: '⭐', color: '#ff6b6b' },
  // ...
];
```

### 1.3 任务管理

**任务数据结构**
```javascript
{
  id: "唯一标识符",
  title: "任务标题",
  description: "任务描述（可选）",
  category: "所属分类",
  completed: false,
  createdAt: "2024-09-13T12:00:00Z"
}
```

**功能操作**
1. **添加任务**
   - 点击「添加新任务」展开表单
   - 输入标题（必填）和描述（可选）
   - 自动归类到当前分类

2. **完成任务**
   - 点击左侧复选框切换完成状态
   - 已完成任务移至底部「已完成」区域
   - 带划线效果和透明度变化

3. **编辑任务**
   - 点击右侧编辑图标进入编辑模式
   - 可修改标题和描述
   - 保存或取消操作

4. **删除任务**
   - 点击右侧删除图标
   - 直接删除，无确认对话框
   - 建议后续添加撤销功能

### 1.4 数据持久化

**存储方案**
- 使用浏览器 localStorage
- 存储键：`board-data-v1`
- 自动保存，无需手动操作

**数据结构**
```javascript
{
  tasks: [...],
  notes: [...],
  activeCategory: "home"
}
```

**未来计划**
- [ ] 云端同步（WebDAV / 私有服务器）
- [ ] 数据导出（JSON / Markdown）
- [ ] 数据导入和迁移
- [ ] 定时备份

### 1.5 界面设计

**设计原则**
- 简洁：去除不必要的装饰和复杂交互
- 快速：常用操作一键完成
- 直观：使用图标和颜色辅助识别
- 舒适：合理的间距和圆角设计

**响应式布局**
- 侧边栏固定 256px 宽度
- 主内容区最大宽度 896px，居中显示
- 卡片式设计，带阴影和悬停效果

**配色方案**
- 主色：靛蓝 (#6366f1)
- 背景：浅灰 (#f9fafb)
- 文字：深灰 (#111827)
- 边框：中灰 (#e5e7eb)

## 二、LinuxDo 论坛模块

### 2.1 完整保留功能

- ✅ 主题浏览（最新、热门、置顶）
- ✅ 主题阅读和回复
- ✅ 用户认证和个人资料
- ✅ 搜索功能
- ✅ 书签管理
- ✅ 草稿箱
- ✅ 消息通知
- ✅ 徽章系统
- ✅ 聊天功能

### 2.2 独立性设计

**目录隔离**
所有 LinuxDo 代码位于 `src/modules/linuxdo/`，包括：
- 组件（components）
- 页面（pages）
- 工具函数（lib）
- 状态管理（context）

**路由独立**
- LinuxDo 路由前缀：`/linuxdo/*`
- 内部路由保持原有结构
- 不影响看板模块路由

**状态独立**
- AuthContext：用户认证状态
- AppContext：应用级通知和配置
- 不与看板模块共享状态

### 2.3 集成方式

通过侧边栏「LinuxDo」分类入口：
- 点击后路由跳转到 `/linuxdo`
- 显示完整的 LinuxDo 界面
- 保持侧边栏可见，方便切换

## 三、共享层

### 3.1 AppLayout 组件

**功能职责**
- 渲染统一的侧边栏
- 处理分类切换逻辑
- 管理路由跳转

**设计特点**
- 当前分类高亮显示
- 渐变背景和颜色标记
- 底部信息栏

### 3.2 路由设计

```
/                → 重定向到 /board
/board           → 看板页面（根据 activeCategory 显示内容）
/linuxdo/*       → LinuxDo 模块的所有页面
```

**路由守卫**
- 看板模块无需认证
- LinuxDo 模块内部处理认证状态

## 四、性能优化

### 4.1 已实现优化

1. **代码分割**
   - React.lazy 懒加载所有页面
   - Vite 自动代码分割
   - 按路由分包，减少首屏加载

2. **缓存策略**
   - TanStack Query 数据缓存（LinuxDo）
   - localStorage 本地缓存（看板）
   - 合理的 staleTime 设置

3. **打包优化**
   - Gzip 压缩
   - Tree shaking
   - 资源优化和压缩

## 六、安全性考虑

### 6.1 数据安全

- localStorage 数据不加密（计划中）
- 敏感数据不存储在本地
- LinuxDo 认证 token 安全存储

### 6.2 XSS 防护

- React 自动转义
- DOMPurify 清理富文本（LinuxDo）
- 外部链接安全打开

### 6.3 CSRF 防护

- LinuxDo API 请求包含 CSRF token
- 同源策略保护
